# 🏠 Nest – Shared Household Expense Landing Page

Polished and improved a responsive product landing page for Nest, helping New Zealand flatmates understand and manage shared rent, bills, reminders, and household contributions.

## 📌 Overview

Nest is an early-stage product designed for New Zealand flatmates and head tenants, providing a clearer way to manage shared household expenses.

The project involved transforming the client's existing landing page and design references into a polished, responsive, conversion-focused experience while preserving the existing product direction and functionality.

🌐 **Live Website:** [nesthouse.org](https://nesthouse.org)

## 🎯 Objectives

- Match and refine the client's provided design direction
- Improve visual hierarchy and overall UI consistency
- Create a polished responsive experience across devices
- Clearly communicate Nest's product value
- Improve product presentation and conversion flow
- Integrate a functional early-access signup experience
- Preserve existing functionality while improving the frontend

- **Forms:** Formspree
